Evolve mobile UI

A bookmarklet that turns Evolve into a phone-friendly layout: a bottom bar switches between Game, Resources and Log panels, tabs scroll sideways, and buttons are laid out in a tap-friendly grid.

On a computer, drag this to your bookmarks bar:

Evolve Mobile

Install on a phone

  1. Tap Copy bookmarklet below.
  2. Bookmark any page in your mobile browser (Chrome: ⋮ → ☆; Safari: Share → Add Bookmark).
  3. Edit that bookmark: rename it Evolve Mobile and paste the copied text into the URL / address field.

Use it

  1. Open Evolve and wait for it to load.
  2. Run the bookmarklet (Chrome Android: type Evolve Mobile in the address bar and pick the bookmark; Safari: Bookmarks → Evolve Mobile).
  3. Tap Desktop in the bottom bar, or run it again, to go back to the normal layout.

Run it again after reloading the page — bookmarklets only last until the page is reloaded.
