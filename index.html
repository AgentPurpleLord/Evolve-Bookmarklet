Evolve mobile UI

A bookmarklet that turns Evolve into a phone-friendly layout: a bottom bar switches between Game, Resources and Log panels, tabs scroll sideways, and buttons are laid out in a tap-friendly grid.

Recommended: userscript (Firefox / Chrome, auto-runs and auto-updates)

No bookmark needed. A userscript manager runs the mobile layout every time you open Evolve and keeps itself up to date.

  1. Install Violentmonkey (or Tampermonkey) — Firefox Android: menu → Add-ons → search “Violentmonkey” → +.
  2. Open the script link below and confirm Install.
  3. Open Evolve as usual (a normal bookmark or home-screen shortcut works). The mobile layout switches on by itself on phone-sized screens.
Install userscript

Updates: the manager checks for new versions on its own schedule (Violentmonkey: Settings → update interval; you can also tap Check for updates).

No extensions: bookmarklet

If you can't use an extension, this loader bookmarklet only needs to be saved once — it fetches the newest code each time you tap it, so it never goes stale. You still need to tap it after each page load.

On a computer, drag this to your bookmarks bar:

On a phone: tap Copy loader, bookmark any page, edit the bookmark and paste the text into its URL field.

Use it

  1. Open Evolve and wait for it to load (the userscript does the rest; with a bookmarklet, tap it now).
  2. Switch between Game, Resources and Log with the bottom bar.
  3. Tap Desktop in the bar to go back to the normal layout for this visit.
